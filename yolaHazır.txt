2. MEVCUT KODLARIN DETAYLI İNCELEMESİ, EKSİKLER VE DÜZELTİLECEK YERLER
--------------------------------------------------------------------------------

A. VERİTABANI KATMANI (`server/database.js`):
   1. [KRİTİK PERFORMANS EKSİĞİ] SQLite Varsayılan Modda Çalışıyor:
      - Mevcut `database.js` dosyasında SQLite varsayılan "DELETE" journal modunda çalışmaktadır. Her yazma işleminde veritabanı dosyası kilitlenmekte ve disk I/O darboğazına sebep olmaktadır.
      - Çözüm: `PRAGMA journal_mode = WAL;` ve `PRAGMA synchronous = NORMAL;` aktif edilmelidir.
   2. [KRİTİK RAM OPTİMİZASYONU EKSİĞİ]
      - `PRAGMA temp_store = MEMORY;`, `PRAGMA mmap_size = 268435456;` (256 MB) ve `PRAGMA cache_size = -64000;` (64 MB) eksiktir. Veritabanı RAM yerine diski boğmaktadır.
   3. [ÇÖKME RİSKİ] Eşzamanlı Yazma Kilitlenmesi (Busy Timeout):
      - Eşzamanlı isteklerde `SQLITE_BUSY` hatası alınmaması için `db.configure("busyTimeout", 3000);` eksiktir.
   4. [KRİTİK PERFORMANS AÇIĞI] Veritabanı İndekslerinin (Index) Bulunmaması:
      - `ilanTablo` üzerinde `durum`, `bolgeId`, `hayvanTuru`, `kullaniciId` kolonlarında indeks yoktur. Yüzlerce ilan içinde filtreleme yaparken veritabanı her seferinde "Full Table Scan" yapmaktadır.
      - `talipTablo` üzerinde `ilanId`, `talipId`, `durum`, `bolgeId` kolonlarında indeks yoktur.
      - Çözüm: Tablolar oluşturulurken veya kurulurken ilgili alanlara `CREATE INDEX IF NOT EXISTS` tanımlanmalıdır.
   5. [VERİ BÜTÜNLÜĞÜ AÇIĞI] Atomik İşlemlerin (Transaction) Kullanılmaması:
      - İlan verme, başvuru yapma ve mesaj gönderme işlemlerinde `yayinHakki` düşürme ile ilan/başvuru ekleme işlemleri ayrı sorgularla yapılmaktadır. İşlem ortasında çökme yaşanırsa bakiye düşüp kayıt atılamayabilir.
      - Çözüm: `BEGIN TRANSACTION`, `COMMIT` ve `ROLLBACK` kullanılmalıdır.

B. BACKEND SUNUCU KATMANI (`server/server.js`):
   1. [KRİTİK GÜVENLİK VE YÜK EKSİĞİ] Fail-Fast ve Event Loop İzleyici Yokluğu:
      - Yük altında (%75 ve %80) sunucuyu çökmekten koruyacak `perf_hooks` (monitorEventLoopDelay) mekanizması `server.js` içine entegre edilmemiştir.
   2. [KRİTİK GÜVENLİK EKSİĞİ] Ceza Puanlama ve Otomatik Ban Mekanizması Yokluğu:
      - Bot taramaları (404), bozuk JSON (400) ve yetkisiz erişim (401/403) denemelerine karşı IP bazlı ceza puanı (RAM map) izlemesi yapılmamaktadır.
   3. [GÜVENLİK RİSKİ] Sabit JWT Secret ve Ortam Değişkenleri (Environment Variables) Kullanılmaması:
      - `JWT_SECRET`, `JWT_PUBLIC_SECRET`, `JWT_BOLGE_SECRET` gibi hassas anahtarlar `server.js` içinde string olarak gömülüdür (hardcoded). `.env` dosyası kullanılmalıdır.
   4. [GÜVENLİK RİSKİ] Wildcard CORS Yapılandırması:
      - `res.setHeader("Access-Control-Allow-Origin", "*")` prodüksiyonda kısıtlanmalı veya geçici domain alan adımızla sınırlandırılmalıdır.
   5. [GERÇEK IP MASKELERİ] Cloudflare Başlık Okuma:
      - İstemci IP adresi alınırken `req.headers['cf-connecting-ip']` öncelikli okunmalıdır.

C. FRONTEND VE DEPLOYMENT KATMANI:
   1. Angular uygulamaları dev sunucusunda (`ng serve`) değil, `ng build --configuration production` komutuyla derlenip Nginx tarafından statik dosya olarak sunulmalıdır.
   2. `environment.prod.ts` dosyalarında API adresi geçici domainimizin proxy adresine (`/api`) yönlendirilmelidir.

DOSYA 2: `server/security.js` (YENİ DOSYA OLUŞTURULACAK)
--------------------------------------------------------------------------------
Açıklama: Yük takibi (%75 ve %80), Fail-Fast yanıtı, RAM ceza puanı yönetimi ve Cloudflare API entegrasyonunu barındıran modül.

İçerik:
```javascript
// server/security.js
const { monitorEventLoopDelay } = require('perf_hooks');
const https = require('https');

// Yük İzleyici (BÖLÜM 3 - %75 ve %80 Eşikleri)
const eventLoopDelay = monitorEventLoopDelay({ resolution: 10 });
eventLoopDelay.enable();

// Event loop gecikme threshold'ları (nanosaniye cinsinden)
const THRESHOLD_FAIL_FAST = 50e6; // ~50ms gecikme (%75 yük)
const THRESHOLD_DROP = 100e6;     // ~100ms gecikme (%80 yük)

// RAM Üzerinde Ceza Puanı İzleme Map'i
const ipPenaltyScores = new Map();
const BAN_THRESHOLD = 100;

/**
 * Sunucu yük durumunu kontrol eder.
 * %80 yükte bağlantıyı koparır.
 * %75 yükte veritabanına dokunmadan 503 cevabı döner.
 */
function checkServerLoad(req, res) {
    const lag = eventLoopDelay.mean;
    if (lag > THRESHOLD_DROP) {
        if (req.socket && !req.socket.destroyed) {
            req.socket.destroy(); // %80 Yük: Bağlantıyı anında kapat
        }
        return true;
    }
    if (lag > THRESHOLD_FAIL_FAST) {
        res.writeHead(503, {
            "Content-Type": "application/json",
            "Retry-After": "10"
        });
        res.end(JSON.stringify({
            error: "Sistemde yoğunluk var, lütfen birazdan tekrar deneyiniz.",
            subCode: 503001
        }));
        return true;
    }
    return false;
}

/**
 * IP adresine ceza puanı ekler.
 * Puan 100'e ulaştığında Cloudflare API'sine Ban isteği gönderir.
 */
function addPenaltyPoint(ip, points) {
    if (!ip || ip === '127.0.0.1' || ip === '::1') return;

    const currentScore = ipPenaltyScores.get(ip) || 0;
    const newScore = currentScore + points;
    ipPenaltyScores.set(ip, newScore);

    console.log(`[GÜVENLİK UYARISI] IP: ${ip} | Ceza Puanı: +${points} | Toplam: ${newScore}/100`);

    if (newScore >= BAN_THRESHOLD) {
        banIpOnCloudflare(ip);
        ipPenaltyScores.delete(ip); // Banlandıktan sonra RAM'den temizle
    }
}

/**
 * Cloudflare API'sine IP Engelleme (Block Rule) isteği atar.
 */
function banIpOnCloudflare(ip) {
    const zoneId = process.env.CF_ZONE_ID;
    const apiToken = process.env.CF_API_TOKEN;

    if (!zoneId || !apiToken) {
        console.log(`[GÜVENLİK KORUMASI SIMULASYON] ${ip} 100 puana ulaştı! (Cloudflare API anahtarları tanımlanmadığı için loglandı)`);
        return;
    }

    const postData = JSON.stringify({
        mode: "block",
        configuration: {
            target: "ip",
            value: ip
        },
        notes: "Otomatik Güvenlik Sistemi - 100 Ceza Puanı Aşıldı"
    });

    const options = {
        hostname: 'api.cloudflare.com',
        port: 443,
        path: `/client/v4/zones/${zoneId}/firewall/access_rules/rules`,
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${apiToken}`,
            'Content-Type': 'application/json',
            'Content-Length': Buffer.byteLength(postData)
        }
    };

    const req = https.request(options, (res) => {
        let responseBody = '';
        res.on('data', chunk => responseBody += chunk);
        res.on('end', () => {
            console.log(`[CLOUDFLARE BAN BAŞARILI] IP: ${ip} engellendi.`);
        });
    });

    req.on('error', (e) => {
        console.error(`[CLOUDFLARE API HATASI] IP Banlama başarısız: ${e.message}`);
    });

    req.write(postData);
    req.end();
}

module.exports = { checkServerLoad, addPenaltyPoint };
```

DOSYA 3: `server/cf-cleanup.js` (YENİ DOSYA - CRON SCRIPT)
--------------------------------------------------------------------------------
Açıklama: Sunucuda 30 dakikada bir çalışacak cron görevi. Ban süresi dolan IP'leri Cloudflare Firewall Kurallarından siler.

İçerik:
```javascript
// server/cf-cleanup.js
const https = require('https');
require('dotenv').config();

const zoneId = process.env.CF_ZONE_ID;
const apiToken = process.env.CF_API_TOKEN;

if (!zoneId || !apiToken) {
    console.log("Cloudflare yapılandırması eksik, temizlik iptal edildi.");
    process.exit(0);
}

// Cloudflare Firewall kurallarını listele ve süresi geçenleri sil
const options = {
    hostname: 'api.cloudflare.com',
    port: 443,
    path: `/client/v4/zones/${zoneId}/firewall/access_rules/rules?notes=Otomatik Güvenlik Sistemi`,
    method: 'GET',
    headers: {
        'Authorization': `Bearer ${apiToken}`,
        'Content-Type': 'application/json'
    }
};

const req = https.request(options, (res) => {
    let body = '';
    res.on('data', chunk => body += chunk);
    res.on('end', () => {
        try {
            const data = JSON.parse(body);
            if (data.success && data.result) {
                const now = new Date().getTime();
                data.result.forEach(rule => {
                    const createdOn = new Date(rule.created_on).getTime();
                    // 30 dakikayı (1800000 ms) geçen banları kaldır
                    if (now - createdOn > 30 * 60 * 1000) {
                        deleteRule(rule.id);
                    }
                });
            }
        } catch (e) {
            console.error("Temizlik parse hatası:", e.message);
        }
    });
});

function deleteRule(ruleId) {
    const delOptions = {
        hostname: 'api.cloudflare.com',
        port: 443,
        path: `/client/v4/zones/${zoneId}/firewall/access_rules/rules/${ruleId}`,
        method: 'DELETE',
        headers: {
            'Authorization': `Bearer ${apiToken}`,
            'Content-Type': 'application/json'
        }
    };
    const delReq = https.request(delOptions, (res) => {
        console.log(`[BAN KALDIRILDI] Kural ID: ${ruleId}`);
    });
    delReq.end();
}

req.end();
```

DOSYA 5: `server/server.js` (GÜNCELLEMELER VE ENTENTREASYONLAR)
--------------------------------------------------------------------------------
Açıklama: `security.js`, `dotenv`, Cloudflare IP okuma, ceza puanları ve hata yakalamaları entegre edilecektir.

Değişiklik Detayları:
1. `server.js`'in en üstüne `require('dotenv').config();` ve `const { checkServerLoad, addPenaltyPoint } = require('./security.js');` eklenecektir.
2. Hardcoded JWT stringleri yerine `process.env.JWT_SECRET` vb. kullanılacaktır.
3. HTTP Sunucusu isteği aldığı ilk anda `checkServerLoad(req, res)` çağrılacaktır.
4. İstemci IP adresi `const clientIp = req.headers['cf-connecting-ip'] || req.headers['x-real-ip'] || req.socket.remoteAddress;` ile tespit edilecektir.
5. Bozuk JSON isteklerinde (`safeParse` catch bloğunda): `addPenaltyPoint(clientIp, 25);` çağrılacaktır.
6. Bulunamayan endpoint (404 else bloğunda): `addPenaltyPoint(clientIp, 50);` çağrılacaktır.
7. Yetkilendirme middleware'lerinde (`authenticate`, `authenticatePublic`, `authenticateBolge`) token geçersiz/yetkisiz durumlarda: `addPenaltyPoint(clientIp, 35);` çağrılacaktır.

    set_real_ip_from 108.162.192.0/12;
    set_real_ip_from 190.93.240.0/20;
    set_real_ip_from 188.114.96.0/20;
    set_real_ip_from 197.234.240.0/22;
    set_real_ip_from 198.41.128.0/17;
    set_real_ip_from 162.158.0.0/15;

        root /var/www/public-app;

ADIM 3: GEÇİCİ DOMAIN VE CLOUDFLARE AYARLARI

ADIM 5: ANGULAR UYGULAMALARININ MİGRASYONU VE DERLENMESİ
